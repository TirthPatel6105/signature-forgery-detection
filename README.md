# Signature Forgery Detection using CNN

## 📌 Overview
This project detects whether a signature is genuine or forged using deep learning.

## 🧠 Models Used
- Model 1: Basic CNN (Best Performance)
- Model 2: Regularized CNN
- Model 3: Deep CNN

## 📊 Results
Model 1 achieved highest accuracy (~84%)

## ⚙️ Tech Stack
- Python
- TensorFlow / Keras
- OpenCV

## 🚀 How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run notebook:
   jupyter notebook DLproject.ipynb

## 📁 Dataset
Dataset contains genuine and forged signatures.

## 🔍 Features
- Signature classification
- Signature comparison using feature similarity
